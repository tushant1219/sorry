JUST US — MADAM JI WEBSITE

RUN IT
1. Extract this ZIP.
2. Open the "madamji-perfect-website" folder in VS Code.
3. Install the VS Code extension "Live Server" if needed.
4. Right-click index.html and choose "Open with Live Server".
   (You do not need Node.js or npm for this version.)

ADD PHOTOS AND VIDEOS
1. Put your photos in assets/photos/
   - photo1.jpg
   - photo2.jpg
   - photo3.jpg
   - photo4.jpg
2. Put your videos in assets/videos/
   - video1.mp4
   - video2.mp4
3. If filenames or extensions differ, edit the memoryItems list near the top of script.js.

CUSTOMIZE WORDS
Open index.html and edit the headings, letter, timeline and promises.
Open style.css to change colours, spacing, fonts and animation.

NOTES
- The site uses Google Fonts when the internet is available; fallback fonts work offline.
- The sound button is off by default and only plays a small original chime when clicked.
- Use photos/videos you have permission to use, and keep personal content private.
- If someone has blocked contact, do not use the website to bypass that boundary. A sincere apology should respect their space and choice.
